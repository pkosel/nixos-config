# AGENTS.md

NixOS flake for one host (`frieda`, GNOME desktop). Home Manager runs as a NixOS
module, so there is no separate `home-manager switch`. See `README.md` for
installation and the full command list.

## Layout

- `flake.nix`: inputs, overlays, `nixosConfigurations.frieda`, formatter.
- `hosts/<host>/`: machine-specific config (`configuration.nix`, `hardware.nix`).
- `system/`: NixOS modules, one concern each, imported by a host.
- `home/`: Home Manager modules, imported by `users/philipp.nix`.
- `pkgs/`: packages not in nixpkgs (wired in via overlay in `flake.nix`).
- `scripts/`: install helpers. Do not run `setup-partitions`; it is destructive.
- `todo.md`: prioritised open tasks.

## Conventions

- A module configures one thing and does nothing until imported. Put
  machine-specific settings in `hosts/`, never in a module.
- New files under `system/` or `home/` must be imported somewhere, or they have
  no effect. Flakes only see git-tracked files, so `git add` new files before
  building.
- `nixpkgs` and `home-manager` must track the same release (currently 26.05).
  Bump them together.
- Comments in the repo explain *why* (workarounds, pinned versions). Keep that
  style and add a comment when adding a workaround.
- Nix is formatted with `nixfmt` (`nix fmt`); Lua in `home/editors/nvim` with
  stylua (`.stylua.toml`).

## Checks

Run after any change, in this order:

```sh
nix fmt                                  # format all Nix files
nix flake check                          # evaluate flake outputs
nixos-rebuild build --flake .#frieda     # full build, does not touch the system
```

There is no CI and no test suite; a successful `build` is the real check.

## Do not

- Run `nixos-rebuild switch`/`boot`, `nixos-install` or `nix flake update`
  unless asked. They change the running system or `flake.lock`.
- Use `sudo`.
- Edit `hosts/frieda/hardware.nix` by hand; it is generated by
  `nixos-generate-config`.
- Commit unless asked.
